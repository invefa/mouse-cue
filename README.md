# mouse-cue

鼠标操作预约器。给一段操作流程，它先在屏幕顶部显示提示与倒计时，倒计时结束后在目标位置画出落点标记，再执行动作。期间用户可按 Esc 或点浮层上的取消区中止，中止时输出 `操作失败: 用户取消` 并以退出码 2 收尾。

Rust 单文件实现，零外部依赖，直接调用 Win32，编译产物约 100 KB。

## 计划文件

命令行接收一个文本文件，逐行一个指令。`#` 开头是注释。

```
title=打开语料库面板
detail=点击左侧栏的语料库
countdown=4
move=57,399,侧栏 语料库
click
wait=2400
```

| 指令 | 作用 |
| --- | --- |
| `title=` | 浮层标题 |
| `detail=` | 浮层说明 |
| `countdown=` | 倒计时秒数，0 到 120 |
| `move=x,y[,标签]` | 定位到屏幕坐标并在该处画落点标记 |
| `click` | 在落点单击 |
| `double` | 在落点双击 |
| `wait=毫秒` | 停留 |
| `exec=命令行` | 执行一条外部命令 |

## 浮层

主浮层是置顶无边框窗口，用窗口区域裁剪出 10px 圆角，面板 236/255 不透明度。配色只用灰度：面板 #1e1e1e、描边 #363636、标题 #e8e8e8、说明 #8c8c8c、倒计时 #dcdcdc。层级靠亮度与线宽，不用色相。

位置默认在屏幕右上角，边距 16px。与落点重叠时按右上、左上、右下、左下、上中、下中的顺序换位，取第一个不遮挡目标的位置。

- 左侧是标题与说明。

- 右侧是倒计时秒数，执行阶段换成进度 `3/5`，结束显示「完成」或「已取消」。

- 底部一行写「按 Esc 或点此取消」。

倒计时与执行阶段都可以取消：Esc 走全局按键轮询，浮层右下角有一块取消热区，点它同样中止。

面板用双缓冲绘制，先画到内存位图再整块贴回；读秒只在秒数变化时才重绘，因此不闪。

## 落点标记

一个置顶穿透窗口，跟着目标坐标走，不拦截鼠标。倒计时一开始就出现，不是等到真正点击时才画。

- 形状：一个实心圆里嵌加号，圆不描边。

- 颜色：落位时先把标记窗口挪出屏幕，采样目标点周围七个像素的亮度，再按底色选对比最强的一组。暗底用中灰圆配纯白加号，亮底用浅灰圆配近黑加号。采样完再把窗口移回目标位置显示。

- 动画：出现时从 3.2 倍尺寸收缩到定尺，520ms，缓出。

- 按下状态：圆与加号互换颜色，表示这一下正在发出。

## 输出

结束向标准输出打一行 JSON，错误信息走标准错误。

| 情形 | 退出码 | stdout |
| --- | --- | --- |
| 走完流程 | 0 | `{"status":"ok","step":3,"steps":3,"elapsedMs":6180}` |
| 用户取消 | 2 | `{"status":"cancelled","reason":"user","step":1,"steps":3,"elapsedMs":2400}` |
| 移动不到位等故障 | 1 | `{"status":"error","code":1,...}` |

取消时标准错误额外输出一行 `操作失败: 用户取消`。

## 本机限制与 click.ps1

这台机器上 mouse-cue 进程自己发不出鼠标输入：`SetCursorPos` 返回 0 且不设置错误码，`SendInput` 同样无效，光标停在原地。同一台机器上由 DSH 直接调起的 powershell 进程可以正常发送，因此真正的输入改由 `click.ps1` 在 powershell 里完成。\n\n`click.ps1` 必须先声明 DPI 感知。系统缩放 125% 时，不感知的进程会把传入的物理坐标再乘一次缩放，落点偏右下约四分之一屏宽，而它读回的光标也是逻辑坐标，校验反而通过。脚本开头调用 `SetProcessDPIAware` 之后落点才对齐。

```
mouse-cue 负责：提示、倒计时、取消判定、落点标记、结果输出
click.ps1 负责：倒计时结束后定位光标、按下与抬起、回收结果
```

用法：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File click.ps1 -X 57 -Y 399 `
  -Title "打开语料库面板" -Detail "点击左侧栏的语料库" -Countdown 4 -Hwnd 721714
```

参数：`-X/-Y` 屏幕坐标，`-Title/-Detail` 浮层文案，`-Countdown` 秒数，`-Button` 取 left/double/right，`-Hwnd` 点击前先激活的窗口句柄，`-SettleMs` 点击后浮层保持时长。

脚本内部先生成计划文件启动 mouse-cue，等倒计时结束后检查进程是否已被取消，再自己执行定位与点击。取消时打印 `操作失败: 用户取消` 并返回退出码 2。

## 已知限制

- 浮层宽度固定 560 逻辑像素，长文案会被裁掉。

- 计划文件必须是 UTF-8，带不带 BOM 都能解析；Windows 换行同样可用。

- `exec=` 通过 cmd 执行，整行按 cmd 规则拆分，路径有空格时需要用引号包住整个命令行。
